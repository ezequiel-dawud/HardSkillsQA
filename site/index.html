Como funciona

Onde cada trilha roda

No navegador Trilhas 1, 2, 4

O banco e a API rodam dentro da página (WebAssembly ou JavaScript). Nada que você escreve sai da sua máquina, e nenhum servidor processa nada.

No seu computador Trilhas 3, 5, 7

pytest, carga com k6 e automação com Playwright rodam localmente, a partir do código que está no repositório.

De leitura Trilha 6

CI/CD: você entende e mexe nos pipelines que já vêm no repositório.

Progresso salvo localStorage

Suas respostas ficam no navegador. Quer levar pra outro computador? Clique em Entrar, no topo, e crie uma conta: é só um nome de usuário.

Um módulo conta inteiro com 70% dos exercícios certos ou 70% na prova dele.

Caminho recomendado

Começando do zero? Siga nesta ordem.

Cada trilha usa o que a anterior deixou pronto.

≈ 20h no caminho principal
1 Fundamentos de Teste O que testar e por quê. ~3h30 2 Git e GitHub Pra conseguir baixar o código e entregar o seu. ~2h 3 SQL para QA Investigar e validar dados, a habilidade que mais muda o dia a dia. ~6h 4 Teste de API Status, contrato, e cruzar a resposta com o banco. ~3h 5 Validação com pytest Suas verificações viram testes que rodam sozinhos. ~3h 6 CI/CD para QA Fazer tudo isso rodar a cada mudança e reprovar o build. ~2h30

PostgreSQL e Teste de carga com k6 são aprofundamentos: faça quando as seis acima estiverem firmes, ou antes se o seu trabalho pedir.

Os tempos são estimativas fazendo os exercícios de verdade, não só lendo.

Fundamentos Base

Fundamentos de Teste

A base da profissão, antes de qualquer ferramenta: princípios, níveis e tipos, técnicas pra escolher casos de teste, exploratório e relatar bug.

5 módulos~3h30
Base Base

Git e GitHub para QA

Baixar o código, versionar seus testes, ler o que mudou num Pull Request e entender o vermelho do CI. Destrava as trilhas 3, 5 e 6.

3 módulos~2h
Trilha 1 Dados

SQL para QA

Consultar, validar e investigar dados. Do SELECT às transações, com um SQLite dentro da página.

7 módulos~6hRoda no navegador
Trilha 2 Aprofundamento Dados

PostgreSQL na prática

O mesmo cenário num Postgres de verdade (rodando na página). Tipos reais, datas, texto, FILTER, window functions.

7 módulosRoda no navegador
Trilha 3 Automação

Validação com pytest

As queries de validação viram testes automatizados que rodam no seu terminal e no CI. Projeto real em trilha-3/.

4 módulos~3hRoda no seu computador
Trilha 4 Automação

Teste de API

HTTP, status codes, contrato da resposta, e cruzar o que a API devolve com o que está no banco. API falsa na própria página.

4 módulos~3hRoda no navegador
Trilha 5 Aprofundamento Entrega e carga

Teste de carga com k6

Muitos usuários ao mesmo tempo: medir tempo de resposta e taxa de erro, e fazer a meta de performance reprovar o build. Projeto real em trilha-5/.

4 módulosRoda no seu computador
Trilha 6 Entrega e carga

CI/CD para QA

O que é um pipeline, ler um arquivo do GitHub Actions sem susto, e fazer os testes rodarem sozinhos a cada mudança, reprovando o build quando quebra.

4 módulos~2h30Leitura + repositório
Trilha 7 Automação

Automação web com Playwright

Controlar um navegador de verdade: clicar, preencher formulário, esperar carregamento assíncrono, mockar rede e testar API. Projeto real em trilha-7/, contra um site de treino feito pra automação.

5 módulosRoda no seu computador
