QA Learning

Trilhas de estudo pra crescer como QA, do zero. Cada uma tem a teoria curta e a prática pra fazer de verdade — a maioria roda dentro do próprio navegador. Nunca estudou QA? Comece pela trilha de Fundamentos; o caminho completo está logo abaixo.

8 trilhas 38 módulos 0 instalação pra começar

Como funciona

Nas Trilhas 1, 2 e 4 o banco/API roda dentro do próprio navegador (WebAssembly ou JavaScript) — nada que você escreve sai da sua máquina, nenhum servidor processa nada. As Trilhas 3 (pytest) e 5 (carga com k6) rodam no seu computador, a partir do código no repositório. A Trilha 6 (CI/CD) é de leitura — você entende e mexe nos pipelines que já vêm no repositório. As respostas que você digita ficam salvas no seu navegador (localStorage). Quer levar o progresso pra outro computador? Clique em Entrar, no topo, e crie uma conta — é só um nome de usuário. A barra de cada trilha anda conforme você acerta exercícios e faz as provas; um módulo conta inteiro com 70% dos exercícios certos ou 70% na prova dele.

Caminho recomendado

Se você está começando do zero, siga nesta ordem. Cada trilha usa o que a anterior deixou pronto.

  1. Fundamentos de Teste — o que testar e por quê. ~3h30
  2. Git e GitHub — pra conseguir baixar o código e entregar o seu. ~2h
  3. SQL para QA — investigar e validar dados, a habilidade que mais muda o dia a dia. ~6h
  4. Teste de API — status, contrato, e cruzar a resposta com o banco. ~3h
  5. Validação com pytest — suas verificações viram testes que rodam sozinhos. ~3h
  6. CI/CD para QA — fazer tudo isso rodar a cada mudança e reprovar o build. ~2h30

PostgreSQL e Teste de carga com k6 são aprofundamentos: faça quando as seis acima estiverem firmes, ou antes se o seu trabalho pedir. Os tempos são estimativas fazendo os exercícios de verdade — não só lendo.

Fundamentos
Fundamentos de Teste
A base da profissão, antes de qualquer ferramenta: princípios, níveis e tipos, técnicas pra escolher casos de teste, exploratório e relatar bug. 5 módulos.
Base
Git e GitHub para QA
Baixar o código, versionar seus testes, ler o que mudou num Pull Request e entender o vermelho do CI. Destrava as trilhas 3, 5 e 6. 3 módulos.

Trilhas técnicas

Trilha 1
SQL para QA
Consultar, validar e investigar dados. 7 módulos, do SELECT às transações, com um SQLite dentro da página.
Trilha 2
PostgreSQL na prática
O mesmo cenário num Postgres de verdade (rodando na página). Tipos reais, datas, texto, FILTER, window functions. 7 módulos.
Trilha 3
Validação com pytest
As queries de validação viram testes automatizados que rodam no seu terminal e no CI. Projeto real em trilha-3/. 4 módulos.
Trilha 4
Teste de API
HTTP, status codes, contrato da resposta, e cruzar o que a API devolve com o que está no banco. API falsa na própria página. 4 módulos.
Trilha 5
Teste de carga com k6
Muitos usuários ao mesmo tempo: medir tempo de resposta e taxa de erro, e fazer a meta de performance reprovar o build. Projeto real em trilha-5/. 4 módulos.
Trilha 6
CI/CD para QA
O que é um pipeline, ler um arquivo do GitHub Actions sem susto, e fazer os testes rodarem sozinhos a cada mudança — reprovando o build quando quebra. Usa os workflows que já existem no repositório. 4 módulos.
Trilha 7
Automação web com Playwright
Controlar um navegador de verdade: clicar, preencher formulário, esperar carregamento assíncrono e mockar rede. Projeto real em trilha-7/, contra um site de treino feito pra automação. 4 módulos.
