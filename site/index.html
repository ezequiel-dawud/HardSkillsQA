QA Learning

Trilhas de estudo pra crescer como QA. Cada trilha tem a teoria curta e a prática rodando de verdade no navegador. Comece pela que fizer sentido agora — as outras ficam aqui esperando.

Como funciona

O banco roda dentro do próprio navegador (SQLite via WebAssembly) — nenhuma query que você escreve sai da sua máquina, nenhum servidor processa nada. As respostas que você digita ficam salvas só no seu navegador (localStorage), então continuam lá mesmo se você recarregar a página.

Trilhas

Trilha 1
SQL para QA
Consultar, validar e investigar dados. 7 módulos, do SELECT às transações, com um SQLite dentro da página.
Trilha 2 em breve
PostgreSQL na prática
O mesmo cenário migrado pro banco que você mais encontra no trabalho — diferenças de datas, strings, tipos.
Trilha 3 em breve
Validação com pytest
Transformar as queries de validação em testes automatizados que rodam no CI (pytest + conexão com o banco).
Trilha 4 em breve
Teste de API
HTTP, status codes, contrato de resposta, e cruzar o que a API devolve com o que ficou gravado no banco.

As trilhas "em breve" são só marcadores por enquanto. Quando quiser começar uma, é só pedir.
