Trilha Automação web com Playwright

Escrever scripts que controlam um navegador de verdade: clicar, preencher formulário, esperar carregamento assíncrono, e mockar rede pra testar cenário de erro sem depender do servidor cair de verdade.

Esta trilha roda na sua máquina

Como as Trilhas 3 e 5, não tem prática rodando na página: o Playwright controla um navegador instalado no seu computador. O projeto está no repositório, na pasta trilha-7/. Siga com o trilha-7/README.md aberto do lado.

O alvo é um site de treino separado, feito só pra automação e já publicado (código em qa-learning-treino, se quiser olhar), com um data-testid em cada elemento importante. Não precisa clonar nem subir nada, só o Node.js que já instalou pra rodar o Playwright. Sem conta, sem Docker, sem pip install.

Bônus

Opcional, antes do Módulo 1: montar um projeto Playwright do zero (sem nada pronto) pra entender de onde cada arquivo do projeto já pronto vem.

Módulo 0 · Bônus
Montar o projeto do zero
npm init, instalar o Playwright, escrever o playwright.config.js e o primeiro teste na mão, sem nada pronto — pra entender de onde vem cada arquivo que o Módulo 1 em diante já te entrega.

Obs. do Ezequiel: recomendo só dar uma olhada nesse módulo pra entender o que tem por trás, sem digitar tudo na mão. Pra seguir a trilha de verdade, baixe o .zip com o projeto do Módulo 1 em diante já montado.

Provas por módulo

Questões de múltipla escolha corrigidas na hora, mais uma questão aberta por prova, que não entra na nota e existe pra você comparar o seu texto com uma resposta modelo. Nota ≥ 70% = módulo firme. Faça depois de estudar o módulo correspondente.

Módulos

Módulo 1
Preparar e primeiro teste
o que é automação de navegador, instalar o Playwright, o alvo publicado, data-testid, locators, primeiro teste de login
Módulo 2
Page Object Model, formulário e validação
test.describe/beforeEach, organizar o projeto com Page Object Model, expect().toBeVisible/toBeHidden, validação de campo
Módulo 3
Cenários do site de treino
login compartilhado entre testes, loading assíncrono, paginação, estado vazio, modal, upload de arquivo, drag and drop
Módulo 4
Rede e preparo pra CI
page.route pra mock/intercept, atalho de login via localStorage, rodar headless, o que muda pro CI
Módulo 5
Testes de API
o fixture request do Playwright, chamar API sem abrir navegador, autenticação com token (Authorization: Bearer), test.describe.serial pra testar o ciclo de vida de um recurso

Desafio final

Depois do Módulo 5, um exercício que combina tudo: UI e API no mesmo teste. Não é corrigido por múltipla escolha, é prático, com o verificar.py conferindo os critérios.

Pré-requisito

Ter o código na máquina e o Node.js instalado. O Módulo 1 cobre a instalação passo a passo. Fazer a Trilha 3 (pytest) antes ajuda a pegar o jeito de "teoria + projeto que roda local", mas não é obrigatório.
