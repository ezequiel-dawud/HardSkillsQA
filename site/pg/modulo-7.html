Módulo 7 — Window functions

OVER, PARTITION BY, ROW_NUMBER/RANK/DENSE_RANK, running SUM, LAG/LEAD

Antes de começar

GROUP BY colapsa o grupo numa linha. Window function faz uma conta olhando um conjunto de linhas (a "janela") mas mantém cada linha no resultado. É como ter o total do grupo ao lado de cada item.

  • função() OVER (PARTITION BY x ORDER BY y) — a janela. PARTITION BY divide em grupos; ORDER BY ordena dentro de cada grupo (importa pra ranking e acumulado). Os dois são opcionais.
  • Ranking: ROW_NUMBER() (1,2,3… sem empate), RANK() (empate ocupa a posição e pula: 1,1,3), DENSE_RANK() (1,1,2).
  • Acumulado: SUM(x) OVER (ORDER BY y) — soma correndo linha a linha.
  • Vizinhos: LAG(x) / LEAD(x) — valor da linha anterior / seguinte (dentro da partição).
  • Top-N por grupo: numere com ROW_NUMBER() OVER (PARTITION BY g ORDER BY v DESC) numa subconsulta e filtre WHERE rn <= 3 por fora (não dá pra filtrar window function no WHERE direto).

Dois exemplos

Teoria

  • COUNT(*) OVER () — total geral em toda linha. AVG(x) OVER (PARTITION BY g) — média do grupo ao lado de cada linha.
  • ROW_NUMBER() OVER (ORDER BY x DESC) — posição no ranking.
  • SUM(x) OVER (ORDER BY d ROWS UNBOUNDED PRECEDING) — acumulado (o ROWS… é o default quando há ORDER BY).
  • LAG(x, 1) OVER (ORDER BY d) — valor anterior; x - LAG(x) OVER (…) = variação.
  • Window function não pode ir no WHERE / HAVING — embrulhe numa subconsulta/CTE e filtre lá fora.
