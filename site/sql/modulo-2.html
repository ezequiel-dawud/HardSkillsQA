Módulo 2 — NULL e filtros finos

IS NULL, COALESCE, CASE

Teoria

  • NULL = "sem valor". Não é 0 nem ''. Não dá pra comparar com =: use IS NULL / IS NOT NULL.
  • Qualquer conta com NULL vira NULL (10 + NULL = NULL).
  • COALESCE(a, b, c) — devolve o primeiro argumento que não for NULL.
  • CASE WHEN condição THEN x WHEN ... THEN y ELSE z END — o "if" dentro do SELECT. Bom pra criar faixas/rótulos.
  • Truque útil: SUM(CASE WHEN cond THEN 1 ELSE 0 END) conta quantas linhas batem uma condição.

Olhar de QA: linha com data_fechamento IS NULL = defeito ainda aberto. NULL onde não devia é uma classe inteira de bug.
