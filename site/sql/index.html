Trilha SQL para QA

Sair do zero e chegar em consultar, validar e investigar dados com confiança. Cada módulo tem a teoria curta em cima e os exercícios rodando de verdade logo abaixo, num SQLite que vive dentro da própria página.

Módulos

Módulo 2

Módulo 3

Módulo 4

Módulo 5

Módulo 7

Provas por módulo

Questões novas, corrigidas na hora: você escreve a query e o resultado é comparado com o esperado (mais algumas de múltipla escolha). Nota ≥ 70% = módulo firme. Faça depois de estudar o módulo correspondente.
