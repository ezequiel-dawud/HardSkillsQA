Trilha Teste de carga com k6

Simular muita gente usando o sistema ao mesmo tempo, medir o que acontece com tempo de resposta e taxa de erro, e transformar a meta de performance num portão que reprova o build.

Esta trilha roda na sua máquina

Como a Trilha 3, não tem prática rodando na página — o k6 é um programa que roda no seu terminal. O projeto está no repositório, na pasta trilha-5/. Siga com o trilha-5/README.md aberto do lado.

Você vai precisar do k6 (winget install k6 --source winget) e do Python que já instalou na Trilha 3. Sem conta, sem Docker, sem pip install — o servidor-alvo de treino usa só a biblioteca padrão.

Módulos

Módulo 1
Preparar e primeiro teste
o que é teste de carga, instalar o k6, VU / iteração / duração, o smoke test, ler o resumo
Módulo 2
Anatomia de um script
default function, http.get/post, check(), sleep(), options, group(), tags
Módulo 3
Carga de verdade: stages e thresholds
rampa de carga, thresholds como portão, smoke / load / stress / spike / soak, ler o "quebrou"
Módulo 4
Dados e CI
SharedArray, correlação (pegar valor da resposta), dado que varia, portão de performance no GitHub Actions

Pré-requisito

Ter o repositório na máquina e o k6 instalado. O Módulo 1 cobre a instalação passo a passo. Fazer a Trilha 4 (Teste de API) antes ajuda, mas não é obrigatório.
